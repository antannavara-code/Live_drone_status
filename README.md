# flutter_app

A new Flutter project.

## Backend

The app talks to the fleet service on port `8000` by default.

- Desktop and web default to `http://localhost:8000`
- Android emulators default to `http://10.0.2.2:8000`
- For a different host, run Flutter with `--dart-define=API_BASE_URL=http://<host>:8000`
